1. Control Group vs. Experimental Group

To determine whether a specific variable actually causes a change, scientists compare test subjects against a baseline standard.

⚖️ Control Group

The baseline group that receives no special treatment or 0 units of the Manipulated Variable (MV). Used for direct comparison.

🧪 Experimental Group

The test group (or groups) that receives the Manipulated Variable (MV) treatment being evaluated.

Example: Testing a battery-cooling heatsink on an electric motor.
Control Group: Motor running without any heatsink attached.
Experimental Group: Identical motor running with the custom heatsink attached.

2. Types of Scientific Data

Data recorded during an experiment falls into two distinct categories depending on how it is measured.

📊 Quantitative Data

Numerical measurements made with tools (rulers, stopwatches, thermometers, scales). Always includes numbers and units! (e.g., 24.5 m/s, 12.0 Volts).

👁️ Qualitative Data

Descriptive observations captured using senses (color shifts, texture, smell, sound differences). (e.g., solution turned dark blue, motor vibrated loudly).

3. Multiple Trials & Sources of Error

A single test run is never enough to prove a conclusion. Scientists perform multiple trials (repeat measurements) and calculate averages to minimize random measurement errors.

Key Reliability Factors:

  • Sample Size: Testing a larger group reduces the impact of outliers or unusual individual variations.
  • Systematic Errors: Calibration mistakes in instruments that shift all readings off by the same amount.
  • Random Errors: Unpredictable environmental fluctuations (slight draft in room, slight reaction time delay).
Average = (Trial 1 + Trial 2 + Trial 3) / Total Number of Trials
